# Schematic

Place KiCad or PDF schematics here after the actual ESP32-S3 board, pump current,
MOSFET module, sensor supply and enclosure are selected. Include:

- Power tree and fuse ratings
- MOSFET gate pull-down
- Flyback/suppression path
- TEST interlock location
- ADC divider/filter and I²C pull-ups
- Board pinout and strapping-pin verification
